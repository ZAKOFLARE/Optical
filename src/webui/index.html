静态站点

绑定域名 → 指定目录 → 网关直接吐文件；没有命中站点的 Host 继续走路由转发
优先级：WAF → 规则 → 静态站点（按 Host 精确匹配，`*` 兜底）→ 路由转发。站点命中但文件不存在时返回 404，不会悄悄转给上游。
root 支持相对路径，按配置文件所在目录解析；目录越界与软链穿越都会被拒绝。

动态项目

Go / PHP / Java / Python / .NET / Node：网关负责拉起进程、端口映射、CORS 与启停
映射方式：应用只监听 127.0.0.1:port，网关按 host + path_prefix 把它挂到域名上；启停只影响进程，路由始终存在（停了返回 503，不是 502）。

二次验证 (TOTP)

            

              

                

                  

                

                  

                

                

                

                  
                  扫码导入验证器；二维码由网关本地渲染，不走任何外部服务。
                

                

                  

                

                  
                  保存前必须验证一次：算法对不上时当场拦下来，不会让你存完就登不进去。
                

              

              
用 Google Authenticator / 1Password 扫码或手输 Base32。

              
SHA1 是 RFC 6238 默认值，只为兼容验证器；口令用 argon2id，会话令牌是 256 位 CSPRNG。
